# Language Translation Tool

## About the Project
This project is a web-based Language Translation Tool developed as part of the CodeAlpha AI Internship.

It allows users to enter text, select a source language and a target language, and translate the text using an online translation API.

## Features
- Simple and user-friendly interface
- Multiple language options
- Online text translation
- Input validation
- Displays translated text on the webpage

## Technologies Used
- HTML
- CSS
- JavaScript
- MyMemory Translation API

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Enter the text you want to translate.
4. Select the source and target languages.
5. Click the Translate button.
